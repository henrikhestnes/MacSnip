# MacSnip 1.0.2

The app is now built with the hardened runtime.

- macOS library validation is on and `DYLD_*` environment variables are ignored, so another process can no longer inject code into MacSnip to borrow its Screen Recording access.
- The release is signed with the same certificate as 1.0.1, so the Screen Recording permission carries over from 1.0.1. No settings need to change.
- **Upgrading from 1.0.0:** grant Screen Recording one last time. In **System Settings → Privacy & Security → Screen & System Audio Recording**, remove MacSnip (−), add it again, and relaunch it.
- No functional changes.

Requires macOS 14 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

```sh
brew install --cask henrikhestnes/tap/macsnip
```

Existing Homebrew users can run `brew update` followed by `brew upgrade --cask macsnip`.

Or download `MacSnip.zip`, unzip it, quit any running copy, and replace **MacSnip.app** in **Applications**.

This build is signed with a self-signed certificate and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper.
