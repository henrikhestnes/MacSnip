# MacSnip 1.1.0

Two new features.

- **Recent Screenshots:** the menu bar icon has a new submenu listing the last 10 screenshots in your save folder, newest first, with thumbnails. Click one to copy it to the clipboard again; hold ⌥ and click to show it in Finder.
- **Capture on release from the toolbar:** the capture toolbar has a checkbox for capturing as soon as the mouse is released, so you can switch between that and confirming the selection without opening Settings. It is the same setting as in Settings and is remembered for later captures.
- Signed with the same certificate as 1.0.1 and 1.0.2, so the Screen Recording permission carries over. **Upgrading from 1.0.0:** in **System Settings → Privacy & Security → Screen & System Audio Recording**, remove MacSnip (−), add it again, and relaunch it.

Requires macOS 14 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

```sh
brew install --cask henrikhestnes/tap/macsnip
```

Existing Homebrew users can run `brew update` followed by `brew upgrade --cask macsnip`.

Or download `MacSnip.zip`, unzip it, quit any running copy, and replace **MacSnip.app** in **Applications**.

This build is signed with a self-signed certificate and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper.
