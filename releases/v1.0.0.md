# MacSnip 1.0.0

The first release of MacSnip, an Ubuntu-style screenshot tool for the macOS menu bar.

- Press **Hyper+P** to freeze the screen and select an area, a display, or a window.
- Screenshots are copied to the clipboard and saved to `~/Pictures/Screenshots` with sortable `yyyy-mm-dd_hh.mm.ss` names.
- The last selection is restored next time, and a thumbnail appears after each capture.
- Launch at Login is turned on the first time MacSnip runs.

Requires macOS 14 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

```sh
brew install --cask henrikhestnes/tap/macsnip
```

Or download `MacSnip.zip`, unzip it, and move **MacSnip.app** to **Applications**.

On first launch, enable MacSnip in **System Settings → Privacy & Security → Screen & System Audio Recording**, then quit and reopen it.

This build is ad-hoc signed and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper.
