# MacSnip 1.1.1

- **Capture on release remembers your last selection:** the capture overlay now opens on the area you captured last, as it already did without capture on release. Press Enter or the shutter to capture it again, or drag a new area to capture that instead. Whichever you capture becomes the starting selection next time.
- Signed with the same certificate as 1.0.1 and later, so the Screen Recording permission carries over.

Requires macOS 14 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

```sh
brew install --cask henrikhestnes/tap/macsnip
```

Existing Homebrew users can run `brew update` followed by `brew upgrade --cask macsnip`.

Or download `MacSnip.zip`, unzip it, quit any running copy, and replace **MacSnip.app** in **Applications**.

This build is signed with a self-signed certificate and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper.
